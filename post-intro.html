欢迎来到我的个人网站

2026-06-10 · 阅读时间 2 分钟

你好！这是我用来整理个人名片、项目经验和技术写作的个人网站。

网站结构

  • 首页：快速展示我是谁、关注什么，以及最重要的项目入口。
  • 关于：整理个人简介、技能方向和阶段性经历。
  • 项目：记录正在建设和计划补充的项目。
  • 博客：沉淀学习笔记、项目复盘和工具实践。
  • 联系：保留 GitHub 和其他后续补充的联系方式。

技术实现

这个站点继续保持轻量：纯 HTML、CSS 和 JavaScript，没有构建步骤，可以直接部署到 GitHub Pages。

  • 响应式布局，适配桌面和移动端。
  • 深色 / 浅色主题切换，并保存用户偏好。
  • 中英双语切换，通用站点文案会记住选择。
  • 博客先使用静态 HTML，后续可以逐篇扩展。

后续计划

下一步会补充真实项目、联系方式、头像和更完整的经历。这里也会逐渐变成一个更有个人痕迹的长期主页。
