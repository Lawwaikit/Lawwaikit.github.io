Content Strategy

内容策略方案

先诊断现状短板，再给出 4 套可预览的内容架构方向，供你挑选。

Diagnosis

现在的短板

01

内容单薄、占位多

项目状态多为「建设中 / 待补充」，博客空白，访客看不到真实成果。

02

首页 Hero 太泛

「你好，我是 Lawwaikit」缺乏定位与记忆点，没说清「你是谁、能帮什么」。

03

关于页是占位时间线

经历区写的是「下一步将替换」，没有真实故事，可信度弱。

04

项目无案例细节

只有一句话 + 标签，缺少背景 / 做法 / 结果，不像作品集。

Foundation

无论选哪套，都建议先补齐

A

一句有力定位

用「我帮 X 做 Y」替代「你好我是 X」，例如「帮团队把测试做得更稳的工程师」。

B

真实头像 / 照片

比纯文字更有温度；没有则用有设计感的字母标识（现有 LW 占位可升级）。

C

3–4 个真实项目

哪怕是小工具 / 学习项目，也要写出背景、你做了什么、结果如何。

D

真实经历时间线

教育 / 工作 / 关键项目，按时间排，建立可信背景。

E

多渠道联系方式

邮箱 + GitHub + （微信 / LinkedIn 占位），降低联系门槛。

F

一个「Now」板块

「现在在做什么」——成本低、个性强，让人看到你是鲜活的人。

Options

四套内容架构方案

A · 现状精修

保留结构 · 低风险
NOW · 正在做 __
  • 保留现有 5 页结构，逐页填真实内容。
  • 首页加「Now」横条 + 3 个真实项目卡 + 最新笔记入口。
  • 关于页时间线换成真实经历，加头像。
  • 博客从空白恢复为「笔记 / 资源」列表。
适合：想稳中求进、先填内容再谈重构

B · 作品集优先

Portfolio-first
  • 把「项目」做成站点核心，首页即强项目展示。
  • 项目页升级为 case-study（挑战 / 过程 / 结果 / 指标 / 技术栈 / 截图）。
  • 关于页精简为支撑；写作降为「最新 3 篇」附属。
  • 视觉上给项目大图占位与更强排版对比。
适合：想用作品说话、未来求职 / 接单

C · 写作 / 知识花园

Writing / Digital Garden
#测试#AI#自动化#复盘
  • 把博客从空白变成核心，做成「数字花园」。
  • 带分类、标签、精选；内容可 evergreen，非纯时间倒序。
  • 加「资源 / 书签 / 工具」收藏区。
  • 关于页强调「学习者 / 写作者」身份。
适合：想以内容 / 思考建立影响力

D · 单页个人站

Personal OS · One-pager
Now · About · Projects · Writing · Uses · Contact
  • 所有内容收进一个精致滚动页，导航锚点跳转。
  • 新增「Uses」板块（常用工具 / 软件 / 硬件）——个性强、成本低。
  • 维护最简单、加载最快、最易统一风格。
  • 博客仍可作独立子页，主站只列最新几篇。
适合：内容尚不多、想极简统一快速上线

Recommendation

我的建议

短期（现在就能做）：先走 A · 现状精修——结构不动、风险最低，把「通用内容清单」里的 6 项补齐（尤其一句定位、真实项目、Now 板块）。这能最快消除「占位感」，且和已做好的 Clay Cool 视觉完全兼容。

若你更想一鼓作气：选 D · 单页，把内容收进一个滚动页 + 新增「Uses」板块，最易做出「真实设计师感」且维护最省心；博客保持独立子页、主站只展示最新几篇即可。

B / C 更适合你已有清晰作品或写作节奏后再切换，不必现在决定。

你挑中方向后，我可以直接按该方案重写对应页面的内容与结构（仍用现有 Clay Cool 样式），并给出每页的「内容填写模板」。
