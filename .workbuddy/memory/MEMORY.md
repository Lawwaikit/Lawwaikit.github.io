# 长期记忆（项目级）

## 设计偏好（重要）
- 用户明确排斥"AI 生成痕迹"的设计：**禁用** 蓝/紫等 AI 常见推荐配色、**避免** 过度规整对称布局、**避免** 过于统一的字号层级、**避免** 通用淡入淡出动效。

- 适用于本个人站的视觉风格决策。

## 最终选定视觉方向（2026-07-13）
- **Clay Cool（方案 05）+ C3 配色（Teal & Slate）** 已全站落地：圆角克制（大面14/按钮12/导航16/导航链接10/图标12，微芯片药丸）、奶油冷灰蓝底 `#EEF3F2`、主色青碧 `#2E8B86`、辅色板岩 `#5C7C84`、Quicksand+Nunito+DM Mono 字体、柔和阴影+悬浮上移、两枚冷色 blob 背景。
- **实现机制**：所有页面 `<body class="clay">` + 引入 `css/clay-cool.css`（整文件限定 `body.clay` 作用域），因此**不改**共享的 `css/style.css` 与博客动态逻辑；换肤只需改 `css/clay-cool.css` 或切 `body.clay` 类名。
- 8 套备选配色存档于 `design-system/palettes.json`（W1-W4 暖、C1-C4 冷），可随时替换 `:root` 变量切换。
- 用户习惯：先要"差异化方案"再"选定一套应用全站"；认可"配色方案=颜色令牌"语义（换色不改结构）。

## 技术栈
- 纯静态站点，无构建步骤，部署到 GitHub Pages。HTML/CSS/JS 直接手写。
- 双语（中/英）通过 `data-i18n` + `js/main.js` 的字典切换；深色模式用 `data-theme` + localStorage。
- 博客为动态系统：`data/blog/index.js`（注入 `window.__BLOG_INDEX`）+ `js/blog.js`（marked 渲染 markdown）。改样式时**不要动**这些逻辑/类名，否则会破坏功能。
- **当前临时状态（2026-07-13）**：为"专注内容"已**暂时移除**中英文切换 + 日间/夜间模式按钮（7 个页面 nav 中的 `<li class="nav-actions">` 已删）；`js/main.js` 中 `savedTheme/savedLang` 硬编码为 `'light'`/`'zh'`（恒定中文+日间，可恢复）。**博客页当前为空白**（保留顶部博客按钮 + page-header 占位「内容筹备中」），博客动态逻辑文件未删，恢复只需改回 `blog.html`。
